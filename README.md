## 📊 Project Overview

This project presents an **Industrial Energy Consumption Analysis Dashboard** developed using **Microsoft Power BI**.

The objective is to transform industrial energy consumption data into an interactive business intelligence dashboard that helps analyze:

*  Energy consumption patterns
*  Industrial sector energy usage
*  Consumption trends over time
*  Energy source contribution
*  Regional/industrial distribution
*  Key energy performance indicators
*  Patterns and variations in industrial energy demand

The project demonstrates an end-to-end **Data Analytics and Business Intelligence workflow**, including data preparation, transformation, modeling, DAX-based calculations, and interactive visualization.

---

#  Project Objectives

The primary objectives of this project are:

1. Analyze industrial energy consumption using historical data.
2. Identify major patterns and trends in energy usage.
3. Compare energy consumption across different industrial categories.
4. Analyze the contribution of different energy sources.
5. Develop meaningful KPIs for energy monitoring.
6. Build an interactive Power BI dashboard for data-driven analysis.
7. Present complex energy data through clear and decision-oriented visualizations.

* Other relevant energy-related variables

The dataset was prepared and transformed before being used for dashboard development.

---

#  Data Preparation & Transformation

The raw dataset was processed using **Power Query** before building the analytical model.

The data preparation workflow included:

* Data loading
* Data type correction
* Missing-value handling
* Column transformation
* Data cleaning
* Standardization of categorical fields
* Removal/handling of unnecessary fields
* Creation of analysis-ready columns
* Preparation of the dataset for Power BI modeling

The objective of the transformation stage was to create a clean and consistent dataset suitable for visualization and analytical calculations.

---

#  Data Modeling

The cleaned dataset was loaded into **Power BI Desktop** and prepared for analytical reporting.

The Power BI model supports:

* Aggregation of energy consumption
* Time-based analysis
* Category-wise comparisons
* Energy-source analysis
* KPI calculations
* Interactive filtering

The model was designed to allow users to explore the data dynamically through Power BI filters and visual interactions.

---

#  DAX & Analytical Measures

DAX was used to create analytical measures and KPIs required for the dashboard.

The calculations support analysis such as:

* Total Energy Consumption
* Average Energy Consumption
* Consumption by Industry
* Consumption by Energy Source
* Time-based consumption analysis
* Percentage contribution
* Comparative analysis
* Other dashboard-level KPIs

Using DAX measures allows the dashboard to dynamically respond to filters and user selections.

## Option 2 — Open the Interactive Power BI Dashboard

The complete Power BI report is provided as a `.pbix` file.

### Step 1 — Download the repository

Clone the repository:

```bash
git clone https://github.com/anandpdt/industrial-energy.git
```

Or download the repository as a ZIP file from GitHub.

### Step 2 — Open the Power BI file

Navigate to:

```text
PowerBi/
```

and open:

```text
energy dashboard.pbix
```

using **Microsoft Power BI Desktop**.

### Step 3 — Explore the Dashboard

Once opened in Power BI Desktop, you can:

* Apply filters
* Interact with charts
* Explore different categories
* Analyze energy consumption
* Inspect DAX measures
* Explore the underlying data model

> **Note:** A public Power BI Service link is not provided for this project. The `.pbix` file is included in the repository so that the complete report can be opened locally using Power BI Desktop.
