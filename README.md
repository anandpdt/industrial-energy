## 📌 Project Overview

This project analyzes **U.S. industrial combustion energy consumption for 2014** using **Microsoft Power BI**.

The project follows a complete data analytics workflow:

**Raw Data → Data Cleaning → Transformation → DAX → Interactive Dashboard → Insights**

The objective is to transform raw industrial energy data into meaningful insights about energy consumption across different **fuel types, industrial sectors, states, facilities, and combustion unit types**.

The Power BI dashboard provides both a high-level overview of industrial energy consumption and detailed facility-level operational analysis.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze industrial energy consumption by fuel type.
- Compare energy consumption across different industries.
- Compare energy consumption across U.S. states.
- Identify the largest energy-consuming facilities.
- Analyze energy consumption by combustion unit type.
- Analyze facility-level energy consumption.
- Explore regional energy consumption patterns.
- Identify the top and bottom energy-consuming fuels.
- Identify the top and bottom energy-consuming industries.
- Identify the top and bottom energy-consuming states.
- Build an interactive two-page Power BI dashboard.
- Develop meaningful KPIs for industrial energy analysis.
